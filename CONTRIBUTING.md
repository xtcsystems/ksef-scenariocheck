# Contributing

KSeF Guard is a bounded public-core probe. Contributions must stay inside the approved scope:

- no more than five built-in scenario types;
- no production invoice transport;
- no customer-specific ERP integration;
- no tax/legal certification claims;
- no hosted customer data;
- no paid-product implementation.

Use synthetic or sanitized fixtures only. Run the CI commands documented in `.github/workflows/ci.yml` before opening a pull request.
