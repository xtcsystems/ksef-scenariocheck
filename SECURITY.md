
# Security policy

Report vulnerabilities privately through this repository's **Security** tab using private vulnerability reporting or a draft Security Advisory. Do not open a public issue containing exploit details, secrets, customer information, invoice content, credentials, tokens, certificates or private keys.

The current implementation branch is prerelease software. Supported-version commitments will be stated only when a public release is authorized.

Normal execution is local and has no network or telemetry path. The input contracts have no fields for invoice payloads, NIP values, credentials, tokens, certificates, private keys, URLs, commands, scripts or arbitrary free text.
